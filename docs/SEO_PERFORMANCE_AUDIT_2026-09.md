# تدقيق SEO والأداء — سبتمبر 2026

## النطاق

تمت مقارنة الملاحظات الواردة من تحليل الموقع مع كود المشروع ونسخة إنتاج محلية مبنية من الفرع `fix/seo-performance-mobile`. أُصلحت الملاحظات المثبتة فقط، بينما تُركت الإجراءات التي تحتاج بيانات أو صلاحيات خارجية دون تنفيذ تلقائي.

## النتائج والقرارات

| الملاحظة | الحكم | الإجراء |
|---|---|---|
| غياب `og:image` و`twitter:image` | مثبت في بعض Metadata القديمة | إنشاء `public/images/og-default.webp` بمقاس 1200×630 وربطه بالـMetadata العامة وصفحات الدول والمدونة والألعاب والسياسات والفيديوهات |
| وجود GA4 دون حدث تحويل واضح | مثبت | إبقاء GA4 مؤجلًا حتى `requestIdleCallback` أو أول تفاعل، وإضافة حدث `trial_booking_click` لروابط WhatsApp دون إرسال نص الرسالة أو بيانات شخصية |
| hreflang مفقود أو غير متبادل | مثبت جزئيًا | إضافة خريطة إقليمية متبادلة للصفحات السبع (`ar-AU`، `ar-CA`، `ar-DE`، `ar-SA`، `ar-AE`، `ar-GB`، `ar-US`) مع `ar` و`x-default` |
| بطء TTFB وتكرار قراءة Supabase | مثبت كفرصة تحسين | فصل وحدة الخادم وإضافة cache لمدة ساعة مع tags، وإبطال `country-content` بعد تعديل سجلات الدولة |
| تأخير معالجة صورة Hero | مثبت كاحتمال قابل للقياس | إبقاء `priority` و`fetchPriority` وإيقاف معالجة Next وقت الطلب للصورة الثابتة الصغيرة، مع السماح بجودة 60 |
| حجب Ahrefs وSemrush وYandex في robots | ليس خطأً مؤكدًا | لم يُغيّر؛ الحجب قرار تحكم بالزحف وليس إصلاح SEO عامًّا |
| رفع Disavow للروابط السامة | غير قابل للإثبات من التقرير وحده | لم يُنفذ؛ يتطلب ملف روابط كاملًا من Search Console/Semrush ومراجعة بشرية، كما أن Google تقصر الأداة على حالات محددة [1] |
| توسيع الصفحة الرئيسية و`/quran` إلى عدد كلمات ثابت | توصية تحريرية لا خطأ تقني | لم يُنفذ في دفعة الأداء؛ عدد الكلمات ليس معيارًا كافيًا وحده لجودة الصفحة |

## التحقق المحلي

نجحت الفحوص التالية بعد التعديلات:

| الفحص | النتيجة |
|---|---|
| TypeScript (`tsc --noEmit`) | ناجح |
| ESLint مع `--max-warnings=0` | ناجح |
| Production build | ناجح؛ توليد 61 صفحة ثابتة |
| `git diff --check` | ناجح |
| HTML المبني محليًا | يحتوي `og:image` و`twitter:image` بمسار `og-default.webp`، وcanonical خاص بالصفحة، وخريطة hreflang الإقليمية |
| الدفع | لا توجد ملفات دفع ضمن diff، ولم تُضف أزرار دفع |

## حدود القياس

قياس Lighthouse CLI غير متاح في بيئة التنفيذ الحالية، لذلك لا أقدّم رقمًا جديدًا مصطنعًا لـLCP. الأرقام المرسلة من Lighthouse تبقى قياسًا ميدانيًا لعينة جهاز وشبكة محددين، ويجب إعادة القياس على Vercel Preview أو Production بعد النشر. قيمة LCP للجوال `5.7s` تستحق المتابعة، لكن نجاح FCP وCLS وTBT لا يثبت وحده أن LCP عولج نهائيًا.
