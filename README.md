# أكاديمية الحافظ المتميز اون لاين 🎓📱

موقع أكاديمية تعليمية عصرية متخصصة في تحفيظ القرآن الكريم وتأسيس اللغة العربية عبر الإنترنت.

## الميزات الرئيسية ✨

### 🌐 التعددية اللغوية
- دعم كامل للعربية والإنجليزية والفرنسية
- واجهة RTL/LTR ديناميكية حسب اللغة المختارة
- ترجمة احترافية لجميع المحتوى

### 🎨 التصميم الحديث
- واجهة مستخدم احترافية وسهلة الاستخدام
- تصميم استجابي كامل (Mobile-First)
- ألوان احترافية (أخضر داكن #1a4d2e، ذهبي #d4af37)
- تأثيرات Hover ناعمة وانتقالات سلسة

### 📱 الميزات الرئيسية
- **صفحات محتوى شاملة**: عن الأكاديمية، المعلمين، المراجعات، المكتبة
- **ألعاب تعليمية**: مطابقة الحروف، مسابقات قرآنية
- **مدونة محسّنة للـ SEO**: 3 مقالات أصلية بمحتوى فريد
- **نظام أسئلة شاملة**: 50 سؤال متكرر مع أكورديون تفاعلي
- **نموذج تواصل آمن**: معالجة آمنة للرسائل مع التحقق

### 🔐 الأمان والخصوصية
- معالجة آمنة للبيانات الحساسة
- حماية من هجمات XSS والحقن
- سياسة خصوصية وشروط استخدام شاملة
- HTTPS وتشفير بيانات المستخدم

### 📊 التحسينات التقنية
- **SEO متقدم جداً**:
  - Schema.org structured data (Article, Organization, Course, LocalBusiness)
  - Meta tags محسّنة لكل صفحة
  - Sitemap و robots.txt ديناميكيين
  - Open Graph و Twitter Card tags

- **الأداء**:
  - Lazy loading للصور
  - Code splitting وتحميل ديناميكي
  - Caching ذكي
  - تحسينات Web Vitals

- **لوحة التحكم الشاملة**:
  - إدارة الباقات والأسعار
  - إدارة المعلمين
  - مراجعة الرسائل والتعليقات
  - تخصيص الإعدادات (النصوص، الألوان، معلومات الاتصال)

### 👤 نظام الحساب
- تسجيل دخول وإنشاء حسابات آمن
- التحقق من البيانات
- واجهة سهلة الاستخدام
- جاهز للربط بنظام الدفع لاحقاً

## البدء السريع 🚀

### المتطلبات
- Node.js 18+
- pnpm (أو npm/yarn)

### التثبيت
```bash
# نسخ المشروع
git clone <repository-url>
cd v0-project

# تثبيت الاعتماديات
pnpm install

# تشغيل خادم التطوير
pnpm dev
```

سيكون الموقع متاحاً على: `http://localhost:3000`

### النشر
```bash
# بناء المشروع
pnpm build

# اختبار البناء
pnpm start
```

### نشر على Vercel
```bash
# باستخدام Vercel CLI
vercel deploy
```
